# K8sAgentMesh brand assets

Display assets for the K8sAgentMesh brand — direction: **Viking North-Cross
Constellation Compass** (board-locked on ISI-6046, kit approved 2026-10-17,
acceptance card `ba1755b0`).

| File | Size | Use |
|---|---|---|
| `banner.png` | 1200x630 | README banner and repo social preview |
| `logo.png` | 512x512 | Primary mark on navy tile — docs, cards |
| `avatar.png` | 512x512 | GitHub org avatar (circle/square-crop safe) |
| `favicon.png` | 32x32 | Browser tab favicon |

Full logo suite (master, mono-dark, reverse, favicon ladder, SVG sources) and
the brand guide live in the identity kit; the **canonical brand tokens**
(`--k8sam-*` CORE palette) live in one place only: `brand/tokens` in the
[`k8sAgentsMesh-website`](https://github.com/K8sAgentMesh/k8sAgentsMesh-website)
repo. Changes to tokens go through PR to that directory; do not redefine them
inline anywhere else.
